# chyi-archive
# 齐豫资料档案 | Chyi Yu Archive

一个以齐豫为中心的个人资料整理项目，收集并归档历年采访、报道、文字记录、影像线索及相关人物资料，尽量保留原始出处，方便查阅与交叉检索。

🌐 **网站：** https://chyi-archive.github.io/

## 收录内容

- 齐豫本人采访、自述与专题报道
- 同行、友人及合作伙伴对齐豫的回忆与描述
- 历年新闻、杂志、报刊与网络文章
- 广播、电视、演出与影像资料线索
- 与作品、职业经历及相关人物有关的补充资料

## 整理原则

本档案优先保留可追溯的原始来源，并尽量区分本人原话、媒体描述与后续转载。部分旧网页、影音页面或历史链接可能因原站失效而无法继续访问。

## 关于本项目

这是一个**非官方、非商业的个人资料整理项目**，主要用于资料保存、查阅与交流。站内外部链接及原始材料的版权归各自权利人所有。

如发现来源错误、失效链接或有值得补充的原始资料，欢迎通过本仓库提出 Issue。
